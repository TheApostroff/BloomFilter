# Biblioteca Bloom Filter App

## Backend (Python + FastAPI)
- Rulează serverul:
  ```bash
  pip install -r backend/requirements.txt
  uvicorn backend.main:app --reload --port 8000
  ```

## Frontend (React)
- Rulează aplicația:
  ```bash
  cd frontend
  npm install
  npm start
  ```

## Spellcheck
- Folosește LanguageTool Public API pentru corectare automată.
